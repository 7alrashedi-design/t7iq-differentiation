# T7IQ Differentiation — MVP

نسخة أولية لمنصة التمايز الذكية تحت نطاق:

`diff.t7iq.com`

## الفكرة
المنصة لا تبدأ من "أنشئ نشاطًا"، بل من **بيانات تعلم الطالب**.  
تحلل التشخيص والتقدم المستمر ثم تقترح للمعلم تجربة تعلم جاهزة ومتمايزة، مع أقل عدد ممكن من المدخلات.

## الاستخدام في البرنامج
1. تدريب المعلم في ورشة/برنامج تأهيلي.
2. بعد الاجتياز يُفعّل حسابه.
3. يرفع التشخيص الأولي أو يستورده.
4. تبني المنصة ملف تعلم ديناميكي للطلاب.
5. تعرض الدروس القادمة بصيغة متكيفة مع احتياج الفصل.
6. بعد كل تنفيذ تُحدّث حالة الإتقان وتُحسن التخطيط التالي.

## التشغيل محليًا
```bash
npm install
npm run dev
```

ثم افتح:
`http://localhost:3000`
