# خارطة تنفيذ MVP

## Sprint 1 — الهيكل والواجهة
- واجهة RTL
- تسجيل الدخول
- الفصول
- الطلاب
- صفحة "رحلة اليوم"
- درس مقترح ببيانات تجريبية

## Sprint 2 — التشخيص وخريطة الإتقان
- استيراد CSV/Excel
- ربط السؤال بالمهارة
- حساب حالة الإتقان
- صفحة خريطة الفصل

## Sprint 3 — محرك التوصية
- تحديد المجموعات المرنة
- اكتشاف الفجوات السابقة
- اقتراح L1/L2/L3
- تبرير مختصر للتوصية

## Sprint 4 — دورة التنفيذ
- اعتماد الدرس
- تقويم ختامي
- تحديث الإتقان
- توليد توصية الدرس التالي

## Sprint 5 — التدريب والمتابعة
- حالة اجتياز البرنامج
- تفعيل الحساب
- ملف نمو مهني
- تقارير شهرية مختصرة
