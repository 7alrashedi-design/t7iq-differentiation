# المعمار التقني v0.1

## الواجهة
Next.js + TypeScript + RTL

## قاعدة البيانات
Supabase مستقل للمشروع:
- Auth
- PostgreSQL
- Row Level Security
- Storage

## الطبقات
1. Curriculum Map
2. Skills Graph
3. Student Learning Model
4. Differentiation Rules
5. Learning Intelligence Engine
6. AI Generation Layer
7. Teacher Experience Layer

## مبدأ الخصوصية
لا تُرسل بيانات حساسة للذكاء الاصطناعي إلا بالحد الأدنى اللازم، ويُفضّل استخدام معرفات داخلية بدل الأسماء في محركات التوليد.

## MVP data flow
Diagnostic result
→ skill mastery update
→ learner state
→ lesson recommendation
→ differentiated paths
→ exit ticket
→ mastery update
→ next lesson recommendation
